# Sezione database e script per il salvataggio dei dati

In questa sezione sono presenti i componenti principali del database e degli script legati ad essi.

- **PostgreSQL**: database di servizio.
- **Clickhouse**: database OLAP per l'analisi dei dati in tempo reale.
- **Script di salvataggio dati**: si occupa di generare dati di esempio per PostgreSQL.
- **Script ELT**: si occupa copiare i dati da PostgreSQL a Clickhouse.
