# Sezione servizi streaming ed elaborazione dati

In questa sezione troverai informazioni sui servizi di streaming ed elaborazione dati disponibili nel progetto BigIntensive. Ogni servizio è descritto con dettagli sulle sue funzionalità, requisiti e modalità di utilizzo.
In particolare questa sezione comprende:

- **Kafka**: si occupa di ricevere i dati in tempo reale dai client, elaborarli e inviarli al database tramite Kafka Stream .
- **Spark**: si occupa di eseguire calcoli complessi e fornire risultati utili per il monitoraggio delle prestazioni degli utenti.
