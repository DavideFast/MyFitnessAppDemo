# Servizi disponibili

In questa sezione troverai informazioni sui servizi disponibili nel progetto BigIntensive. Ogni servizio è descritto con dettagli sulle sue funzionalità, requisiti e modalità di utilizzo.
Questa sezione comprende:

- **Simulatore di Utenti**: simula il comportamento degli utenti, generando dati di frequenza cardiaca e non solo durante le corse.
- **Backend**: si occupa di gestire le richieste dei client, elaborare i dati e fornire le risposte appropriate.
- **Frontend**: si occupa di centralizzare il flusso dei dati e attivare il servizio da simulare
