# Servizi disponibili

In this section, we will provide an overview of the available services in the project.
Each service is described with details about its functionalities, requirements, and usage instructions.
This includes:

- **User simulator**: simulates user behavior, generating heart rate data and more during runs.
- **Backend**: handles client requests, processes data, and provides appropriate responses.
- **Frontend**: centralizes the data flow and activates the service to be simulated.
